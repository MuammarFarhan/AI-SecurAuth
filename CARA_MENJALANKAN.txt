====================================================================
   PANDUAN MENJALANKAN SISTEM AI-SecurAuth
   AI-Based Risk Authentication & ATO Defense System
   Mata Kuliah: AI for Security (PjBL)
====================================================================

PERSYARATAN:
  - Python 3.10 / 3.11 (sudah terinstal)
  - XAMPP (MySQL + phpMyAdmin) → Download: https://www.apachefriends.org/
  - Browser modern (Chrome / Edge)

====================================================================
LANGKAH 1: INSTALL XAMPP & JALANKAN MySQL
====================================================================
  1. Download & install XAMPP dari https://www.apachefriends.org/
  2. Buka XAMPP Control Panel
  3. Klik [Start] pada Apache dan MySQL
  4. Buka browser → http://localhost/phpmyadmin

====================================================================
LANGKAH 2: IMPORT DATABASE
====================================================================
  1. Buka phpMyAdmin (http://localhost/phpmyadmin)
  2. Klik tab "Import" di menu atas
  3. Pilih file: D:\AI-SecurAuth\database.sql
  4. Klik tombol "Go" / "Impor"
  5. Database "ai_securauth" akan otomatis terbuat dengan semua tabel

  Atau bisa juga dengan cara:
  1. Buka phpMyAdmin
  2. Klik "New" di sidebar kiri
  3. Buat database bernama: ai_securauth (Collation: utf8mb4_unicode_ci)
  4. Pilih database ai_securauth → klik "Import" → pilih database.sql

====================================================================
LANGKAH 3: BUAT VIRTUAL ENVIRONMENT & INSTALL DEPENDENSI
====================================================================
  Buka PowerShell / Command Prompt di folder D:\AI-SecurAuth\ lalu:

  > python -m venv env
  > .\env\Scripts\Activate.ps1        (PowerShell)
  > .\env\Scripts\activate.bat        (CMD)
  > pip install -r requirements.txt

====================================================================
LANGKAH 4: KONFIGURASI .env (JIKA PERLU)
====================================================================
  Buka file .env dan sesuaikan:

  DB_HOST=localhost
  DB_USER=root
  DB_PASSWORD=          ← Kosong jika XAMPP default
  DB_NAME=ai_securauth
  DB_PORT=3306

====================================================================
LANGKAH 5: JALANKAN APLIKASI
====================================================================
  > .\env\Scripts\python.exe app.py
  
  Atau setelah activate env:
  > python app.py

  Buka browser: http://localhost:5001

CATATAN PENTING:
====================================================================
  - Password di database menggunakan bcrypt hash
  - Hash yang tersimpan di seed data adalah untuk password "Admin@123"
  - Jika hash tidak cocok (error login), jalankan script berikut:
    > python -c "from werkzeug.security import generate_password_hash; print(generate_password_hash('Admin@123'))"
    Lalu update tabel users di phpMyAdmin dengan hash baru.

  - File model ML (.pkl) untuk XGBoost dan Random Forest ada di folder models/
  - Saat ini simulator menggunakan rule-based scoring (tanpa model .pkl)
  - Untuk integrasi model penuh, letakkan file .pkl dari notebook minggu 5-6 ke folder models/
